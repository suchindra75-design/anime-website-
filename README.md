# The Nocturne Experience

An interactive, scroll-driven manga story for a (placeholder) spirits brand, **Vigilia Spirits**.
It recreates the experience, structure, motion language and interactions of
*The Notturno Experience* (santionispirits.com, Active Theory × Plan8) with **original**
illustrations drawn in code, original copy, free fonts and synthesised sound.

See [`docs/REFERENCE.md`](docs/REFERENCE.md) for the analysis of the reference site and
[`docs/REPORT.md`](docs/REPORT.md) for what was implemented and how it was verified.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173 (add ?gate to force the age gate again)
npm run build      # type-check + production build into dist/
npm run preview    # serve the production build
```

Requires Node 20+.

## Stack

| Concern | Choice |
| --- | --- |
| Build | Vite + TypeScript (strict) |
| Rendering | three.js — two WebGL canvases: illustrations **behind** the DOM text, 3D objects **in front** |
| Motion | GSAP + ScrollTrigger, Lenis smooth scrolling |
| Illustration | SVG generated by TypeScript (`src/art`), rasterised to GPU textures on demand |
| Sound | Web Audio synthesis (no audio files) |
| Fonts | Smythe (display), Nunito 900 (UI), DM Sans 300 (body) — self-hosted via Fontsource |

## How it works

- **Plates** (`src/gl/plate.ts`) — every `<div class="plate" data-art="…">` in `index.html` is a WebGL quad
  that copies the element's on-screen box every frame. Layout, sticky pinning and responsive rules stay in
  CSS; shaders only draw. Plates inside a `[data-panel]` are clipped to the panel frame.
- **Programs** (`src/gl/shaders.ts`) — `art` (ink texture with line boil, melt, accent recolouring, fill mask),
  `solid`, `tone` (screentone), `brush` (title backdrop), `splash` (rising ink), `vortex`, `smear`
  (pointer-driven displacement), `stream` (pouring liquid) and a post pass (scroll-velocity streaks + grain).
- **Melt** — the signature transition: columns of pixels slide with per-column noise, leaving drips.
  `state.in` (0→1) drips content into place; `state.out` (0→1) drips it away.
- **Accent colour** — art uses the key colour `#ff00ff` wherever the visitor's chosen flavour should show;
  the shader swaps it at runtime, so choosing a bottle recolours the liquid, robe and eyes everywhere.
- **Textures** (`src/gl/textures.ts`) — SVGs are rasterised at the size they are displayed (bucketed, capped
  per device), queued to avoid jank and evicted when far away.
- **Scenes** (`src/scenes/*`) — per-chapter choreography and interactions:
  - Hand — *Hold & move*: the hand follows the pointer, the surface smears (trail texture).
  - Flavours — *Choose flavor*: hover shimmer, click / arrow keys to choose.
  - Pour — *Hold & pour*: tilt, stream, fill; completes automatically if you scroll past.
  - Vortex — *Hold*: the whirlwind spins up and lifts the saint.
  - Collection — 3D bottle carousel (buttons, arrow keys, swipe) and 3D martini glass.

## Customising

- **Copy** — all text lives in `index.html`; flavours (names, notes, ABV, colours) are in `src/core/state.ts`.
- **Brand marks** — `src/art/props/wordmark.ts`, `medallion.ts`, `ornament.ts`, `squiggle.ts`.
- **Illustrations** — `src/art/{figures,scenes,props}/<name>.ts`. Preview one with
  `node scripts/render-art.ts <outDir> src/art/scenes/portal.ts` (macOS Quick Look render).
  To use licensed bitmap art instead, replace a module's `draw()` output with an `<image href>` or extend
  `ArtTextures` to load a URL.
- **Art review** — `npm run dev`, then open `/dev/gallery.html` (contact sheet of every illustration;
  `?group=figures|scenes|props`, `&h=420` for row height). Add `?perf` to the site URL to log per-illustration
  generation and rasterisation timings in the console, or `?profile` to record per-frame JS/GPU cost and
  texture uploads in `window.__profile`. These are dev-only.
- **QA switches** (work in any build) — `?gate` shows the age gate again, `?nowebgl` forces the plain-SVG
  fallback, `?nobitmap` forces the canvas texture upload path that Safari and Firefox use, `?debug` exposes
  `window.__app` for scripted testing.
- **Colours / type** — CSS tokens at the top of `src/styles/base.css`; plate colours in `COLORS` (`src/gl/plate.ts`).

## Performance notes

- JS ≈ 250 KB gzipped (three ≈ 136 KB, GSAP + Lenis ≈ 49 KB, app + art generators ≈ 66 KB).
- Illustrations are generated and rasterised lazily as you approach them (about 0.1–0.6 s each, off the
  critical path); only the first chapter is prepared behind the loader.
- Pixel ratio is capped at 2 (1.5 on touch devices) and textures at 2560 px (2048 on touch devices).
- The back canvas stops drawing while the opaque collection/footer sections cover it.

## Accessibility & fallbacks

- Real text for every caption and heading; illustrations carry `role="img"` labels.
- Keyboard: skip link, focusable nav, hold buttons (Space/Enter), radio group for flavours, carousel arrows.
- `prefers-reduced-motion`: no smooth scrolling, melts become cuts, no line boil or streaks.
- Touch devices get explicit **Hold** buttons instead of press-anywhere; landscape phones see a rotate prompt.
- No WebGL: the same SVG art is shown as CSS backgrounds.
